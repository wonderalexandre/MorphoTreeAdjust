# Documentation Guide

This directory gathers the documentation for the public `MorphoTreeAdjust`
core.

## Recommended Entry Point

If you want to use or integrate the repository, start with:

- [public_core_api.md](./public_core_api.md)

The public API guide covers both CASF paths:

- `ComponentTreeCasf` for order-preserving attributes;
- `ComponentTreeCasfNonIncreasing` for supported non-order-preserving
  bounding-box attributes.

Runnable examples are available for:

- [Python](../examples/core_python_api_example.py)
- [C++](../examples/core_cpp_api_example.cpp)

## Maintenance

If you are maintaining the code, use:
